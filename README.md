# Leisure schedule: prompt and optional interactive tool

**Leisure is a biological and psychological necessity, not a luxury.** It supports mood regulation, attention restoration, and mental balance. This framing guides the schedule method and the interactive generator.

This repository is a public place to publish, adapt, and update the method—not the definition of the methodology. The prompt/template works in ChatGPT or any text-based assistant, on paper, or outside this repository. The browser tool is optional.

## Base rules

- Leisure only: no work, study, chores, or obligations.
- Exactly two session types: Real-world and Digital. Real-world is the default.
- Self-sufficient, immediately startable, free/low-cost activities are preferred.
- Every digital session must have a short reason; the chosen weekly maximum is strict.
- After each session, review what it took, what it gave, and whether to repeat.
- Weekly review asks which real-world session improved mood most, whether the digital maximum was exceeded, and what real-world alternative could replace or complement digital leisure.

The optional 20% digital ceiling is an additional planning constraint, not a replacement for the core rules or any applicable core-protocol scoring, safety, or weekly calculations.

## Publication and community review

Proposed schedules belong in the submission process, not directly in the canonical collection. The required path is **propose → maintainer review → approve → publish**. The interactive tool prepares a draft only; a person reviews and submits it, and a maintainer must approve before it is merged into `01-KITS/community-schedules/`.

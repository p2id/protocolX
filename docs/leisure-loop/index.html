Portable planning tool

Leisure schedule organizer

Leisure is a biological and psychological necessity. It can support mood, attention, and mental balance. This tool organizes schedules, not activity content.

2. Digital-cap check

Exactly two types: real-world and digital. Real-world is the default. The 20% maximum is mandatory; any lower limit applies. This cap is neutral, not a judgment.

3. Edit sessions

Activity labels are participant-chosen or blank. No activity is invented, prescribed, ranked, or preferred. Split a session if its medium changes.

4. Weekly review

Review each seven-day week separately. Keep notes private; they are excluded from public export.

5. Export or propose

Exports include the schedule and blank prompts, not reflection answers. Review labels and reasons before sharing.

Propose → Review → Approve → Publish. A maintainer must approve the exact version before publication.

Runs locally without an account or server. Keep private reflections local. The Markdown template works without this tool or repository. Digital leisure is not inherently harmful.

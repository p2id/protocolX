# Activity suggestion refresh process — legacy note

## Current status

The current leisure schedule organizer does not generate, prescribe, rank, or prefer activity content. It organizes session count, timing, type, duration, digital-cap arithmetic, post-session evaluation, and weekly review. Participants choose activity labels or leave them blank.

This file is retained as a scope note for maintainers. Its former activity-building patterns and research-refresh cadence do not drive the current schedule organizer. Do not use this document to populate schedules or reintroduce activity suggestions into the generator.

## Scope boundary

The leisure scheduling workflow maintains the portable template, weekly page, schedule organizer, validation rules, and publication process. It does not research, curate, rank, or refresh activity content.

Any future request to maintain an activity library must be treated as a separate proposal with its own explicit scope and human review. It must not change the current organizer or add activity content to schedules without a separate authorized decision.

## Review and publication

Changes to the leisure schedule method follow **Propose → Review → Approve → Publish**. Review scope, exact session labels, digital reasons and offline alternatives, visible cap calculations, the three post-session prompts, weekly review, privacy, portability, and standalone usability.

An authorized human maintainer must explicitly approve the exact proposed version before merge or publication. A scheduled run, successful validation, or open pull request is not approval.
